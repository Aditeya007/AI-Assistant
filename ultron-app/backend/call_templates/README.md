# Call Template Images Directory

Place your template images here for call detection.

## Required Files

Take screenshots of the following and crop tightly around the indicated UI element:

### WhatsApp Desktop
- `whatsapp_incoming.png` — The incoming call notification/overlay
- `whatsapp_accept.png` — The green "Accept" button
- `whatsapp_hangup.png` — The red "Hang Up" / "End Call" button

### Discord
- `discord_incoming.png` — The incoming call notification/overlay  
- `discord_accept.png` — The green "Accept" button
- `discord_hangup.png` — The red "Hang Up" / "End Call" button

## Tips
- Crop the images tightly around the button/overlay (no extra space)
- Use PNG format for best quality
- The images should match your screen resolution and scale
- Re-capture if you change your display resolution or DPI scaling
